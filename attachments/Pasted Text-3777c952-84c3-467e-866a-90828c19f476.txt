PROMPT MAESTRO — NEXO POS

Sistema integral de ventas, inventario, contabilidad y administración de pequeños negocios

Actúa como un equipo multidisciplinario de desarrollo de software compuesto por:

- Arquitecto de software senior.
- Desarrollador Android experto en Kotlin y Jetpack Compose.
- Desarrollador full-stack especializado en Firebase y Google Cloud.
- Diseñador UI/UX especializado en aplicaciones comerciales.
- Contador profesional especializado en pequeñas empresas.
- Experto en inventarios, comercio minorista y puntos de venta.
- Especialista en ciberseguridad y protección de datos.

1. OBJETIVO GENERAL

Desarrolla una aplicación llamada NEXO POS, un sistema integral de administración de negocios, diseñado principalmente para teléfonos Android, con una interfaz moderna, rápida, intuitiva y completamente en español.

Debe permitir gestionar un negocio desde un teléfono, incluyendo ventas, compras, inventario, proveedores, clientes, créditos, préstamos, contabilidad, reportes, facturación, códigos QR, códigos de barras y sincronización con servicios de Google.

El sistema debe ser útil para:

- Pulperías y abarroterías.
- Farmacias.
- Ferreterías.
- Tiendas de ropa y calzado.
- Minimercados.
- Librerías.
- Tiendas de repuestos.
- Distribuidoras.
- Emprendimientos familiares.
- Pequeñas y medianas empresas.

Debe poder utilizarse con una sola persona o con múltiples empleados.

2. TECNOLOGÍAS Y ARQUITECTURA

Implementa una arquitectura modular, escalable y mantenible.

Tecnologías preferidas:

- Android nativo: Kotlin + Jetpack Compose.
- Arquitectura MVVM y Clean Architecture.
- Backend: Firebase Authentication, Cloud Firestore, Cloud Functions y Cloud Storage.
- Base de datos local: Room.
- Sincronización de datos: WorkManager.
- Inicio de sesión: Google Sign-In mediante Firebase Authentication.
- Google Sheets API.
- Google Drive API.
- Google Calendar API.
- Cámara: CameraX.
- Escaneo: Google ML Kit Barcode Scanning.
- Generación de QR: ZXing o equivalente.
- Generación de PDF.
- Impresión: Android Print Framework, Bluetooth y ESC/POS.
- Gráficos estadísticos interactivos.

Si el entorno de Grok Construir no permite compilar aplicaciones Android nativas, crea inicialmente una PWA responsive, instalable y compatible con Android, preparada para evolucionar posteriormente a una aplicación nativa.

No simules servicios que requieren configuración externa. Implementa las integraciones reales cuando sea posible e indica claramente cuáles necesitan credenciales, permisos, configuración de Firebase o publicación en Google Cloud.

3. REGISTRO, INICIO DE SESIÓN Y NEGOCIOS

El usuario podrá:

1. Iniciar sesión con Google.
2. Crear un negocio.
3. Registrar nombre comercial, dirección, teléfono, logotipo y moneda.
4. Seleccionar el tipo de negocio.
5. Crear varias sucursales.
6. Invitar empleados.
7. Configurar permisos por usuario.
8. Cambiar entre negocios autorizados.

Roles:

- Propietario: control completo.
- Administrador: operaciones y reportes.
- Cajero: ventas y cobros.
- Inventarista: productos y existencias.
- Contador: registros contables y reportes.
- Supervisor: acceso según permisos.

Cada negocio tendrá sus propios datos aislados.

Ningún usuario podrá acceder a información de otro negocio sin autorización.

7. PUNTO DE VENTA — POS

Crear una pantalla de venta optimizada para utilizarse rápidamente desde un teléfono.

Debe contener:

- Buscador de productos.
- Cámara para escanear QR.
- Escáner de códigos de barras.
- Productos favoritos.
- Categorías.
- Carrito de compras.
- Selección de cliente.
- Cantidad.
- Precio unitario.
- Descuentos.
- Impuestos.
- Subtotal.
- Total.
- Métodos de pago.

Funcionamiento

1. El cajero abre Nueva venta.
2. Escanea el QR del estante utilizando la cámara.
3. El producto se agrega automáticamente al carrito.
4. Si escanea nuevamente el mismo producto, aumenta la cantidad.
5. Puede modificar cantidades y eliminar artículos.
6. Selecciona un cliente existente o consumidor general.
7. Elige el método de pago.
8. Confirma la venta.
9. El sistema registra la transacción.
10. Descuenta el inventario.
11. Actualiza la caja.
12. Genera la factura.
13. Registra los movimientos contables correspondientes.

Permitir ventas suspendidas y recuperarlas posteriormente.

Soportar pagos:

- Efectivo.
- Transferencia bancaria.
- Tarjeta.
- Pago mixto.
- Crédito o fiado.

Para pagos electrónicos, registrar su referencia y estado de confirmación. No marcar pagos como confirmados sin una validación real o confirmación autorizada.

Calcular el cambio automáticamente.
